## Info

42 school project.

This project is about discovering the recursion theorem of Kleene!
The challenge is to write a program whose output is its own source code.
The rules are simple:

- Self-replication: The program’s output must be an exact copy of its source code.
- No peeking: You can’t just open the source file and print its contents. That’s cheating.
- No input: The program must be completely self-contained. It can’t ask for any input to do its job.

### Included quines:

- `Colleen`: prints its own source code.
- `Grace`: outputs its source code to `Grace_kid.c` / `Grace_kid.s`.
- `Sully`: outputs its source code to `Sully_X.c` / `Sully_X.s`, compiles and runs it, decrementing `X` (starting at 5) until it reaches 0.

Each quine is implemented in C (`C/`) and in x86-64 Linux assembly (`ASM/`).

## Build

### Dependencies:

- `make`
- `gcc`
- [`nasm`](https://www.nasm.us/)

### Usage:

```bash
# build both implementations
make
# or only one of them
make -C C
make -C ASM
```

The binaries (`Colleen`, `Grace`, `Sully`) are created inside `C/` and `ASM/`. `make fclean` also removes the files generated by `Grace` and `Sully`.
